# После сделки

Веб-тренажёр деловых переговоров: настройте ситуацию, поговорите с виртуальным клиентом и вернитесь к разбору в личном кабинете.

**Сайт:** [posle-sdelki.vercel.app](https://posle-sdelki.vercel.app)

## Возможности

- Настройка темы, отрасли, собеседника, сложности, длительности и формата тренировки.
- Переписка своими словами, подсказки наставника и варианты предложений.
- Явный деморежим без внешнего API и подключаемый AI-собеседник.
- Голосовой ввод и озвучивание средствами браузера; распознанный текст проверяется перед отправкой.
- Личный кабинет: сохранённые разговоры, разбор, наблюдения по навыкам и повтор ситуации.
- Аккаунты участников и администратора. Администратор создаёт и публикует задания в общем каталоге.
- Адаптивный интерфейс, сохранение попыток и восстановление запросов после потери связи.

## Стек

Frontend — React, TypeScript и Vite. Backend — Python и FastAPI. Локальные данные хранятся в SQLite; для Vercel используется PostgreSQL. AI подключается только на сервере через совместимый API; поддержаны Groq и Vercel AI Gateway.

## Локальный запуск

Нужны Python 3.12 и Node.js 20.19+ или 22.12+.

```sh
python3 -m venv .venv
.venv/bin/python -m pip install -r backend/requirements-dev.txt
npm ci --prefix frontend
npm run dev
```

На Windows используйте `.venv\Scripts\python.exe` вместо `.venv/bin/python`.

Откройте [http://127.0.0.1:5174](http://127.0.0.1:5174). API работает на порту 8011, документация — `/api/docs`. Файл `frontend/index.html` не нужно открывать напрямую.

Без ключей доступен деморежим. Для AI скопируйте `backend/.env.example` в `backend/.env`, задайте серверные переменные и перезапустите dev-сервер. Пример содержит только пустые значения. Не добавляйте ключи в frontend и не используйте для них префикс `VITE_`.

## Аккаунты

Участник регистрируется на странице `/#/login`. Администратор создаётся локально с паролем, вводимым скрыто:

```sh
.venv/bin/python scripts/create_admin.py --username admin
```

Стандартных паролей и готовых аккаунтов в репозитории нет. Локальная и публичная базы независимы. Диалоги привязаны к владельцу; история аккаунта открывается после входа, гостевая история автоматически в аккаунт не переносится.

## Проверки

```sh
.venv/bin/python -m pytest backend/tests -q
npm --prefix frontend test
npm --prefix frontend run build
npm --prefix frontend run format:check
```

Интеграционные проверки PostgreSQL требуют отдельной тестовой базы. Автоматические тесты используют фикстуры и не требуют настоящего AI-ключа.

## Публикация

В корне находятся `vercel.json`, FastAPI entrypoint `index.py` и сборочный скрипт `scripts/build-vercel.mjs`. Для нового окружения задайте `DATABASE_URL` и необходимые AI-переменные в серверных настройках Vercel. Создание этого репозитория само по себе не подключает автоматическую публикацию из GitHub.

## Текущие ограничения

Деморежим использует подготовленные правила. AI может ошибаться, его доступность зависит от настроек и лимитов провайдера. Голос зависит от поддержки браузером и разрешения микрофона. История показывает последние 30 разговоров, при этом более старые записи сохраняются и учитываются в прогрессе.

Разбор сейчас отмечает три приёма с подтверждёнными цитатами: выяснение потребности, аргументацию и ответ на возражение. Подробный анализ каждой реплики с выделением неудачных формулировок запланирован, но ещё не реализован в этой версии.

## Что не включено

API-ключи, `.env`, пароли, базы данных, пользовательские переписки, исходные записи созвонов и шаблоны организаторов остаются локально. В Git включены исходники приложения, тесты, собственные иллюстрации сайта и документация.
