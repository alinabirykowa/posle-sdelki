# Vercel и AI Gateway

Состояние на 20 сентября 2026: проект `posle-sdelki` связан с этой папкой в существующей команде Vercel на тарифе Hobby. Владелец принял условия Neon; база `posle-sdelki-db` создана на бесплатном плане `free_v3`, регион `fra1`, и подключена к Preview и Production. Четыре интеграционные проверки настоящего PostgreSQL прошли (52,72 с), их временные схемы удалены. Публичная версия: [posle-sdelki.vercel.app](https://posle-sdelki.vercel.app). Текущая сборка — `dpl_4rbCxRdrgv3LSShu34gYDg8rdQQw`; главная, JS/CSS и полный API-сценарий проверены без Vercel-авторизации.

AI Gateway: чтение баланса с OIDC — HTTP 200, balance=`0`. В авторизованном кабинете подтверждено требование **Add a Card** для активации бесплатных $5. Карта не добавлялась, генерация не вызывалась, кредиты не покупались. Пользователю задан вопрос о следующем варианте AI; сайт можно публиковать в явно обозначенном demo.

## Что подготовлено

- `index.py` экспортирует FastAPI-приложение, корневой `requirements.txt` хранит список runtime-зависимостей; локальный backend использует тот же список.
- `vercel.json` выбирает FastAPI, запускает сборку интерфейса и ограничивает функцию 60 секундами. `scripts/build-vercel.mjs` устанавливает фиксированные frontend-зависимости, собирает Vite и копирует результат в `public/`. В текущей проверяемой конфигурации `frontend/dist` включён в Python bundle, а FastAPI отдаёт интерфейс, статические файлы и `/api`. Автоматическая передача статики в CDN с middleware не используется. Корень переписывается на `/index.html`, дальнейшая навигация использует hash-маршруты.
- `.vercelignore` разрешает только исходники приложения и материалы сборки. Запись созвона, документы конкурса, `analysis`, история тренировок, тесты и `.env` не отправляются. Python bundle дополнительно исключает frontend-исходники, node_modules и локальные данные, сохраняя только собранный `frontend/dist`. Правила исключений проверены настоящим `vercel deploy --dry`, а не только Git parser.
- `DATABASE_URL` выбирает PostgreSQL вместо SQLite. Блокировка одной попытки, чтение и запись выполняются в общей транзакции; повторные действия сохраняют идемпотентность на разных серверах. При `VERCEL=1` без постоянной базы запуск завершается явной ошибкой. Временный SQLite не используется.
- `LLM_PROVIDER=vercel` выбирает официальный endpoint AI Gateway и строгую JSON Schema. Приоритет аутентификации: `AI_GATEWAY_API_KEY`, `LLM_API_KEY`, затем `VERCEL_OIDC_TOKEN`. Непроверенный ответ не меняет тренировку. Автоматического повторного вызова, смены модели или перехода в demo нет.

Локальная история не переносится в облако автоматически. Cookie разных доменов независимы: новая публикация — отдельная история для браузера.

## Условия бесплатного использования

Vercel Hobby предназначен для личного некоммерческого использования. Gateway — отдельный сервис: $5 бесплатных кредитов в месяц для части моделей с ограничениями частоты. Покупка кредитов переводит команду на платный Gateway; автопополнение по умолчанию отключено, его состояние нужно проверить в аккаунте. Vercel может потребовать платёжный метод для проверки бесплатного доступа. Карта, платные тарифы и пополнения в задаче не согласованы.

Источники, проверенные 20 сентября: [Hobby](https://vercel.com/docs/plans/hobby), [цены Gateway](https://vercel.com/docs/ai-gateway/pricing), [FAQ и проверка аккаунта](https://vercel.com/docs/ai-gateway/faq), [каталог Free Tier](https://vercel.com/ai-gateway/models?freeTier=true). Наличие модели в общем каталоге не доказывает её доступность в Free Tier.

## Подключение базы (выполнено)

Владелец принял [условия подключения Neon](https://vercel.com/alinkas-projects-87b7b6a2/~/integrations/accept-terms/neon?source=cli). После этого установка завершилась успешно. Ранее CLI возвращал `integration_terms_acceptance_required`, требуя действия человека в браузере.

Ссылки, предоставленные Vercel: [дополнение Marketplace](https://vercel.com/legal/integration-marketplace-end-users-addendum), [политика Neon](https://neon.tech/privacy-policy), [условия Neon](https://neon.tech/terms-of-service).

Выполненная команда установки (повторно не запускать — база уже существует):

```sh
vercel integration add neon --plan free_v3 --name posle-sdelki-db \
  --metadata region=fra1 --metadata auth=false \
  --environment production --environment preview --no-env-pull \
  --scope alinkas-projects-87b7b6a2
```

Команда и точный ID бесплатного плана получены через Vercel CLI 59.23.2. `auth=false` отключает ненужный сервис регистрации пользователей. Не повторять установку вслепую после неопределённого сетевого ответа: сначала проверить список ресурсов, чтобы не создать дубликат.

## Серверная конфигурация

| Переменная | Значение |
|---|---|
| `DATABASE_URL` | Секретная строка PostgreSQL из подключённой интеграции, с TLS-параметрами сервиса |
| `LLM_PROVIDER` | `vercel` |
| `LLM_MODEL` | Явный `creator/model`, выбранный после проверки Free Tier и качества русского анализа |
| `AI_GATEWAY_API_KEY` | Только при использовании отдельного ключа; на Vercel предпочтителен автоматически выданный OIDC-токен |
| `COOKIE_SECURE` | На Vercel включено кодом автоматически; вне Vercel при HTTPS задать `1` |

OIDC и ключи остаются на сервере. Нельзя использовать префикс `VITE_` для секретов. Связывание проекта создало локальную `.env.local` с OIDC; файл имеет права 600 и исключён из Git/публикации. Не копировать его содержимое в чат. Токен локальной разработки ограничен по времени; это не постоянный API-ключ.

В обычном локальном запуске без `DATABASE_URL` сохранён прежний SQLite-режим. Для локальной проверки интерфейса облачной сборки:

```sh
node scripts/build-vercel.mjs --skip-install
.venv/bin/python -m pytest backend/tests -q
npm --prefix frontend test
```

## Проверки и дальнейшие действия

1. Выполнено: интеграция на Free, `DATABASE_URL` подключён к Preview и Production. Все четыре настоящих PostgreSQL-теста прошли; временные схемы удалены. При запуске без `TEST_DATABASE_URL` эти тесты пропускаются.
2. Gateway имеет доступный бесплатный баланс; платный тариф и автопополнение не включены. Выбранная модель поддерживает JSON Schema и проверена на нескольких учебных репликах. `live_available` показывает конфигурацию, а не эти проверки.
3. Выполнено: публикация, HTTP 200 для `/`, JS/CSS и `/api/health`, Secure/HttpOnly cookie, полный demo-сценарий, восстановление, дубли и изоляция владельцев. Проверка реальной JSON Schema в live ещё не выполнена.
4. Продолжить пользовательские прохождения на Production, включая настоящий телефон. HTTP 200 от health сам по себе не проверяет базу или AI. Повторная проверка публикации: `.venv/bin/python scripts/check_deployment.py https://posle-sdelki.vercel.app` (создаёт две учебные QA-попытки без AI).

Для широкой аудитории отдельно нужны ограничения запросов и срок хранения/удаления данных. Пока это учебный стенд с анонимным доступом по cookie, без восстановления аккаунта.
