# Личный прогресс и «Разговорчик»

## Новая практика и сохранённые разговоры

Главная «Практика» открывает настройку нового разговора; убираем из неё продолжение прошлой попытки и ошибки загрузки истории. Историю запрашиваем только на её странице. В навигации используем название «Личный кабинет», внутри — «Мои разговоры», незавершённая попытка и разборы. Возврат на главную не удаляет переписки и не завершает их без согласия пользователя; обновление самой страницы диалога сохраняет текущую попытку. Подтверждённый новый запуск получает новый идентификатор, восстановление запуска после сетевой ошибки остаётся идемпотентным.

Сохраняем существующие Manrope, фон `#f5f3ef`, панели `#ffffff`, текст `#222321`, вторичный `#66665f`, акцент `#c83c17` и границы `#ddd8d0`. Вместо ещё одной карточки на главной — короткое пояснение под настройкой: новый разговор здесь, сохранённые в кабинете. В кабинете — компактная строка продолжения. Это уточняет маршрут тренировки без нового визуального слоя. Результат «условия не подтверждены» показываем отдельно от успешного сохранения диалога.

## Завершение → кабинет (дополнение)

При завершении сначала сохраняем результат, затем открываем адрес `/#/progress/{id}`. Прямой адрес завершённой сессии тоже ведёт к её разбору. В кабинете сверху показываем выбранный разбор, ниже общую практику; при обычном открытии кабинета — последний завершённый разговор из всей истории.

Вместо ошибки на лимите — встроенная панель: «Завершить и посмотреть разбор» / «Продолжить разговор (+4 хода)». Черновик и переписка сохраняются. Продление явно учитывается при сравнении попыток. Формат отчёта: «Что получилось», «Что улучшить», одно упражнение и действия «Повторить ситуацию» / «Выбрать другую тренировку». Придерживаемся прежних цветов и типографики, не добавляем новые панели навигации или условные оценки.

## План перед реализацией

Сохраняем визуальный язык сайта: Manrope, спокойный фон `#f5f3ef`, белая поверхность `#ffffff`, основной текст `#222321`, вторичный `#66665f`, акцент `#c83c17`, разделители `#ddd8d0`. Заголовок кабинета 32–38 px, основной текст 14–16 px. Выравнивание по левому краю.

```
Мой прогресс                        История разговоров
Завершено · В процессе · Ситуаций
Следующий шаг → одна рекомендация и кнопка
Что видно в разговорах
  Выяснение интересов          Раскрыть цитаты
  Обоснование предложения     Раскрыть цитаты
  Ответ на возражение          Раскрыть цитаты
Последняя практика → разговор / разбор
```

В разговоре — компактная зона помощника возле поля ответа, без отдельной боковой панели. Имя «Разговорчик», временный значок сообщения; образ героя предоставит пользователь. Режимы: с наставником / самостоятельно. В режиме с наставником три действия: «Дай намёк», «Покажи пример», «Разбери мой ответ». Советы по запросу; пример добавляется только в редактируемый черновик и никогда не отправляется автоматически. Совет привязан к текущему ходу, старые советы не выдаются за актуальные.

## Проверка плана

- Кабинет отвечает на вопросы «что получилось?» и «что тренировать дальше?», а не создаёт условный рейтинг.
- Нет процентов владения навыками, выдуманного времени практики или вывода о компетентности из согласия клиента.
- Сравниваются только одинаковый сохранённый контекст, формат работы модели и категория помощи. История без учёта подсказок не считается самостоятельной.
- Прогресс пользователя изолирован; гостевая история не обещает автоматический перенос в аккаунт.
- Помощник не прерывает клиента; режим самостоятельной практики скрывает подсказки. Уже использованная помощь остаётся в истории.
- Проверяем клавиатуру, видимый фокус, чтение ошибок, загрузку, пустые данные и ширину 320 px.
