## Проверка публичного сайта

- Гость: `/api/auth/me` возвращает `user:null`, каталог пуст.
- Неверный вход с корректным Origin возвращает 401, а не ошибку межсайтового запроса.
- Создан рабочий аккаунт администратора команды. Проверены вход, роль `admin`, чтение админки и выход через HTTP.
- В браузере подтверждены вход, выход и повторный вход **после** публикации версии без временных bootstrap-настроек.
- В публичном редакторе подготовлен пример и проверен серверный предпросмотр. В production он **не сохранён и не опубликован**; форма осталась открытой для команды.
- Полный публичный путь с публикацией и тестовым участником не запускался: автоматическая проверка отклонила создание пробных production-записей без отдельного согласия. Пользователю предложено разрешить только публикацию одного подготовленного примера.

## Доступы и начальная настройка

Пароли не включены в этот отчёт. Файлы доступа находятся в игнорируемом `backend/data/`, права `0600`. Публичный доступ: `production-admin-access.txt`; локальные: `admin-access.txt` и `participant-access.txt`.

Существующие production-секреты не скачивались. Для первого администратора использовались только три новые серверные переменные `INITIAL_ADMIN_USERNAME`, `INITIAL_ADMIN_DISPLAY_NAME`, `INITIAL_ADMIN_PASSWORD_HASH`. После успешного входа они удалены из проекта, временный локальный файл хеша удалён, конфигурация без них опубликована. Аккаунт остался в PostgreSQL. Создание идемпотентно и не повышает роль/не меняет пароль существующего пользователя.

## Ограничения

Каталог общий для всех аккаунтов. Разделение по организациям не добавлено. Администратор меняет тексты и девять параметров тренировки; финансовые условия рассчитываются по двум существующим моделям — скидка и сроки/объём. Свободный редактор числовой экономики и сброс пароля через почту не реализованы.
