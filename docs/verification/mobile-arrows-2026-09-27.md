# Стрелки на мобильных устройствах

План: заменить декоративные Unicode-стрелки на имеющиеся SVG-иконки Lucide с `currentColor`. Сохранить Manrope, фон `#f5f3ef`, текст `#222321`, вторичный `#66665f`, акцент `#c83c17`, границы `#ddd8d0` и существующее выравнивание. В кнопках — стрелка рядом с подписью, в карточках — символ прежнего размера. Декоративные иконки скрыты от скринридеров. Проверка плана: это исправление отрисовки в текущем дизайне, новая композиция не нужна; символы шрифта больше не должны определять вид стрелок.

Выполнено: SVG в ссылке «Войти», карточках главной, характере собеседника, истории, переходах между формами входа и прежнем HeroArt. Два декоративных символа ✳ также заменены на SVG. У ссылки входа заданы inline-flex, вертикальное выравнивание и зазор 6 px. Поведение кнопок и маршруты не менялись.

Проверки: TypeScript/Vite build и общий Prettier check прошли. Поиск Unicode-стрелок и emoji-диапазонов по исходникам не вернул совпадений. В браузере подтверждён SVG с `stroke=currentColor` у «Войти», доступное имя содержит только текст. Гостевая главная проверена при 390 px, форма входа при 320 px — горизонтального переполнения нет, ошибок консоли нет. Это проверка адаптивной вёрстки в браузере, не запуск на физическом iPhone; причина проблемы устранена заменой шрифтовых символов на SVG. Новый набор тестов для замены декоративных иконок не добавлялся.
