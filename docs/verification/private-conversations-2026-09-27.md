# Новая практика и личные разговоры

## Что изменено

- «Практика» открывает новую настройку, без карточки прошлой попытки. Переписки не удаляются и не завершаются при уходе на главную. История запрашивается только на странице «Мои разговоры».
- В навигации явно назван «Личный кабинет». Здесь можно продолжить незавершённый разговор, открыть сохранённый разбор или начать новый.
- «Диалог сохранён» отделён от результата «Итоговые условия не подтверждены». Подтверждённые договорённости по-прежнему отмечаются своим итогом.
- После потери ответа запуска доступно явное восстановление первоначального запроса; настройка нового разговора создаёт новый запрос. Ключи запуска разделены по аккаунтам. Старый глобальный ключ не приписывается неизвестному владельцу; существующий разговор остаётся доступен из кабинета.
- Выбранный активный разговор в кабинете обновляется при возврате в видимую вкладку, если завершён в другом месте. Фоновая загрузка не убирает показанный текст; ответы после размонтирования игнорируются.
