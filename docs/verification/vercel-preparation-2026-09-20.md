Создан и связан проект `posle-sdelki` в существующей команде Vercel. Через официальный CLI подтверждён Hobby; запрос API подтвердил active. Сайт ещё не опубликован.

Neon запрошен на конкретном бесплатном плане `free_v3`, регион `fra1`, дополнительная аутентификация выключена. Ответ — `action_required`, `integration_terms_acceptance_required`. Ресурс не создан, ожидается принятие условий человеком. Повторять установку только после этого шага.

## Покрытые риски

Fake-драйвер PostgreSQL проверяет атомарность, savepoint, ошибку подтверждения commit, освобождение соединения, закрепление транзакции и выбор хранилища. Проверки HTTP подтверждают использование транзакции всеми изменяющими endpoint, безопасный 503 и Secure-cookie на Vercel. Они не заменяют настоящий PostgreSQL.

MockTransport проверяет Gateway JSON Schema, приоритет ключей/OIDC, фиксированный адрес, точность цитат, безопасные ошибки 401/402/403/429 и отсутствие автоматических повторов. Настоящая модель не вызывалась.

До завершения: принять условия Neon, создать базу, проверить SQL и сохранение, подтвердить бесплатный доступ Gateway и конкретную модель, выполнить Preview-публикацию и сквозное прохождение, затем Production. Локальные результаты не являются подтверждением готовности облачного стенда.
