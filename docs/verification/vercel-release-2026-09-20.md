## Что исправлено при реальном размещении

Vercel иначе обрабатывает разрешающие правила директорий, чем Git ignore parser: в `.vercelignore` убраны завершающие слеши. Настоящий `vercel deploy --dry` подтвердил 35 исходных файлов без документов, медиа, секретов и локальной истории. [Список](vercel-upload-manifest-2026-09-20.json).

Список runtime-зависимостей перенесён непосредственно в корневой `requirements.txt`, поскольку облачный сборщик отклонил вложенную ссылку. Локальный backend теперь ссылается на этот же список.

Первый вариант API работал, но интерфейс давал 404: `frontend/dist` исключался из функции, а CDN не обеспечивал выдачу файлов. Исключения сужены; скомпилированный интерфейс остаётся в Python bundle и обслуживается FastAPI. Длина `excludeFiles` приведена к допустимой. Исправленная сборка сначала проверена по отдельному адресу, затем назначена основной.
