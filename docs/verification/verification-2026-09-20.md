# Проверка версии 0.1.0 — 20 сентября 2026

Рабочая копия без коммита. Локальный сервис 127.0.0.1:5174, API 8011. Браузер Codex In-app Browser: основной экран 1280×720, эмуляция 390×844, 360×800 и 768×1024. Физический телефон не использовался.

## Автоматические проверки

- Первоначальный независимый прогон: 30 passed, 2 warnings. Вывод — в backend-pytest-initial.txt.
- После добавления транспортных проверок и конкурентного дубля: **44 passed, 2 warnings in 5.00s**. Это запись полученного результата выполнения pytest, а не полный stdout последнего прогона.
- Тесты test_live_transport.py вызывают настоящую live.reply через httpx.MockTransport: timeout, 401, 429, 500, неверный/пустой ответ, успешный ответ, отсутствие тестового ключа в ошибках и логах. Реального провайдера нет.
- Конкурентный одинаковый client_message_id даёт один пользовательский ход и один вызов провайдера.
- Проверка TypeScript и production-сборка Vite завершились успешно. Автоматических frontend E2E-тестов пока нет.

## Браузерные прохождения

1. Scope / deadline / standard / demo: вопрос о приоритете → accept_all → подтверждение. Итог: 160 ч при доступных 120 ч, +5 рабочих дней, остаток 40 000 ₽. Согласие клиента не скрывает невыполнимость.
2. Повтор: вопрос → prioritize_swap → подтверждение. Итог: 120 ч, 15 дней, остаток 80 000 ₽. В разборе реальные вопрос и предложение пользователя.
3. История: обе завершённые попытки открываются; две выбранные записи сравниваются в модальном окне.
4. Discount / cashflow / hard / demo на 390 px: черновик вопроса сохранён после reload. Вопрос раскрывает лимит первого платежа 60 000 ₽. keep_terms отклонён из-за аванса 90 000 ₽. staged_payment принят: 54 000 ₽ + 126 000 ₽, 120 ч, общая цена 180 000 ₽. После подтверждения остаток 60 000 ₽, проект выполним.
5. Повтор сложного кейса чистый, сохраняет cashflow и hard. Завершение без соглашения показывает отсутствие обязательств без фиктивных убытков или прибыли.
6. Перезагрузки страницы и перезапуск backend сохраняют попытки. Восстановлен черновик; завершённая попытка открывает сохранённый разбор.
7. Мобильная панель условий открывается как dialog. Escape закрывает её, фокус возвращается на кнопку условий. Закрытое мобильное меню отсутствует в AX. Открытое меню удерживает Tab/Shift+Tab; Escape возвращает фокус. При 768 px десктопная навигация доступна.
8. Skip-link фокусирует main и сохраняет hash сессии. После finish: scrollY = 0, фокус на main.
9. На 360/390/768 px у проверенных главной, переговорной и результата scrollWidth совпадает с innerWidth. Многострочная реплика отправлена на 360 px, поле ввода увеличивается.
10. После прохождений браузерный журнал ошибок пуст.

## Что ещё не проверено

Реальный AI, экранная клавиатура телефона, потеря сети/ответа в браузере, масштаб 200%, полный аудит контраста и скринридером, нагрузка и публичная среда. Backend-тесты не закрывают автоматически все отдельные строки матрицы приёмки. В деморежиме распознавание вопроса об интересе ограничено ключевыми словами.

Пять созданных при браузерной проверке попыток сохранены отдельно в локальном QA-архиве analysis/qa/manual-sessions-2026-09-20.sqlite3. Пользовательский запуск начинается с пустой историей. Архив не входит в Git.

Финальная проверка сборки: npm run build завершилась успешно (Vite 7.3.6, 1748 модулей, 15.18 с). Собранный интерфейс дополнительно открыт через FastAPI на 127.0.0.1:8011 без Vite; оба кейса загружены. Пользовательская вкладка оставлена на 127.0.0.1:5174.
